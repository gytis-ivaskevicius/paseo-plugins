# Changelog

## Unreleased

- Default owners now come from the signed-in GitHub user and the organizations
  they belong to, instead of a fixed list.
- Item descriptions render as Markdown through Paseo's `Markdown` component.
- Requires `@getpaseo/plugin` 0.15.0 or newer.

## 0.1.0

- Initial release: authored pull requests, human incoming items, a collapsed bot
  divider, and authored issues in one screen.
- Detail pane with review, check, and mergeability state.
- Start or reopen a labelled Paseo agent session from an item.
- Request a review from a repository collaborator.
- Owner list edited in plugin settings, with the viewer required.
